\section{Introduction}

Rook-Ceph contains many powerful tools baked into it's software. One of which is replication.

This Technote strives to illustrate how Rubin Observatory will use replication with our clusters.

The \texttt{chango} cluster (La Serena) hosts the \texttt{elkan} Ceph RGW (S3-compatible) object store, deployed with Rook and managed by Fleet from the \href{https://github.com/lsst-it/k8s-cookbook}{k8s-cookbook} repository. Chango is the long-term storage location for this data.
